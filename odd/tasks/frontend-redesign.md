# Frontend redesign

## Intent
Give the Pollo & Caja operator a confident, warm, tactile daily workspace: fast to scan during a busy counter shift, with clear actions and enough motion to make state changes feel alive without slowing the workflow.

## Product design direction
- Domain: poultry counter, receipt tape, fresh stock, orange flame/heat, cash drawer.
- Color world: roasted orange, cream paper, charcoal ink, sage status green, receipt red.
- Signature: a "service pulse" in the dashboard header and action surfaces—subtle animated heat/availability cues that connect sales, stock, and the open cash drawer.
- Replace generic dashboard cards with layered paper-like surfaces, stronger hierarchy, clearer quick actions, and responsive spacing.

## Tasks
- [ ] Rework visual system and dashboard shell with tactile surfaces, motion, and responsive polish.
- [ ] Validate typecheck/build and prepare the desktop preview for user approval.

## Non-goals
- No database/API behavior changes.
- No merge to dev until the user gives explicit approval.
